# CampusAI – Frontend

This is the React website for CampusAI.

## How to Run

```bash
# Install packages (only once)
npm install

# Start the development server
npm run dev
```

Opens at: http://localhost:5173

> Make sure the backend server is also running at http://localhost:8000

## Pages

- `/login` — Login page
- `/register` — Student registration
- `/dashboard` — Student home page
- `/chat` — AI Assistant (main feature)
- `/history` — Past chat sessions
- `/documents` — View uploaded university documents
- `/notices` — University notices
- `/faqs` — Frequently asked questions
- `/profile` — Edit your profile
- `/admin/dashboard` — Admin home (admin only)
- `/admin/documents` — Upload/delete PDFs (admin only)
- `/admin/notices` — Manage notices (admin only)
- `/admin/faqs` — Manage FAQs (admin only)
- `/admin/users` — View registered students (admin only)
